# Blocs Équations

Résoudre une équation du premier degré avec des blocs : un bloc qui traverse le signe « = » **change de signe**.

- Application web autonome (un seul fichier `index.html`), utilisable hors ligne et installable sur téléphone (PWA).
- Niveaux 1 à 4, tutoriel animé, exercice guidé, cours / fiche de révision exportable en PDF.
- Réglages : nombres entiers, décimaux ou fractions ; nombres positifs uniquement ; taille des nombres ; regroupement automatique ; aide pas à pas ; taille du texte.
- Aucune donnée n’est envoyée : tout reste sur l’appareil. Pas de CDN, pas de traceur.
